# Shardsprint: Counter Pulse

한 줄 소개: **12스테이지 액션 런에서 보스 패턴전, 가챠 코어, 성장 경로 빌드를 결합한 싱글 플레이 웹 액션 게임**.

## 실행 방법
1. `index.html`을 브라우저에서 직접 열기
2. 또는 로컬 서버 실행:
   - `python3 -m http.server 8000`
   - `http://localhost:8000` 접속

## 조작 방법
- 이동: `WASD` / `방향키`
- 대시(회피 무적): `Shift` 또는 `Space`
- 기본 공격: `K`
- 차지 강공격: `J` 홀드 후 릴리즈
- 일시정지: `Esc`
- 메뉴 조작: `Tab`, `Enter`, `Space`

## 주요 특징
- **12 스테이지 진행** (4/8/12 보스 패턴전 포함)
- **보스 패턴 기반 전투**: 광역 탄막, 돌진 베기, 함정 패턴 예고 후 발동
- **가챠 시스템**: 전투로 획득한 조각으로 코어 뽑기, 최대 3개 장착 빌드
- **성장 경로 5종**: 밸런스/공격/기동/방어/반격 특화 경로를 선택해 플레이 방향 확장
- 대시 무적/완벽회피/패링/차지 강공격/히트스톱/넉백/콤보 유지
- 난이도(normal/hard), assist, 화면 흔들림·플래시·파티클 감소 옵션
- Web Audio API 기반 절차 생성 효과음 + localStorage 저장

## 구현된 액션 시스템
- 입력 즉시 이동 + 대시 잔상
- 완벽 회피 보상(대시 자원 회복/조건부 회복)
- 패링/반격 판정
- 기본 베기 + 차지 강공격(폭발 강화 가능)
- 히트스톱, 넉백, 피격 후 무적
- 콤보 카운터와 콤보 유지 시간
- 위험구역(링/크로스) 활성화 패턴
- 보스 패턴 페이즈 전환

## 구현된 이펙트/애니메이션
- 대시 잔상(Afterimage)
- 리본 속도선(Ribbon Trails)
- 공격 궤적/강공격 충격파 링
- 완벽회피 링/패링 링
- 위험 예고선 + 경고 사운드
- 보스 슬래시 경고 아크
- 파편 폭발 파티클
- 저체력 화면 가장자리 경고
- 스테이지 텐션 배경 스트립 애니메이션

## 성취·수집·해금 요소
- 미션 20개
- 업적 24개(숨김 7개)
- 스킨 4종(조건 해금)
- 가챠 코어 6종 (N/R/SR/SSR)
- 코어 장착 3슬롯 빌드
- 랭크(N/R/SR/SSR/E/L/M/G), 결과 리포트, 추천 목표

## 저장(localStorage)
- 최고 점수/랭크/콤보
- 플레이·클리어 누적
- 가챠 조각/가챠 결과/장착 코어
- 성장 경로 선택 기록
- 스킨 해금·장착
- 미션/업적 상태
- 누적 통계(완벽회피, 패링, 보스 클리어 등)
- 설정값(볼륨, 음소거, 난이도, assist, 모션 안전 옵션)
